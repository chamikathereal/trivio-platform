# @apps/web — Trivio Marketing Website

## Overview

The public-facing marketing and information portal for **Trivio — Payment Settlement Intelligence** (`https://trivio.ink`).

## Planned Architecture

- **Framework:** Next.js (App Router)
- **Styling:** Tailwind CSS / modern CSS
- **Deployment Destination:** `https://trivio.ink`
- **Responsibilities:**
  - Value proposition and payment settlement intelligence overview
  - Interactive pricing & MDR fee scenario calculators (powered by `@trivio.ink/core`)
  - Integration guides and developer onboarding pathways
