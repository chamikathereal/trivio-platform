# @apps/docs — Trivio Documentation Website

## Overview

The developer documentation hub for Trivio packages, SDKs, and payment settlement intelligence specifications (`https://docs.trivio.ink`).

## Planned Architecture

- **Framework:** Next.js / Contentlayer / Nextra
- **Deployment Destination:** `https://docs.trivio.ink`
- **Responsibilities:**
  - Complete SDK reference for `@trivio.ink/core`, `@trivio.ink/node`, and `@trivio.ink/react`
  - Financial rounding specifications (round-half-up, bankers rounding, minor-unit arithmetic)
  - Regional acquirer calculation paradigms and fee tier modelling
  - Settlement lifecycle and reconciliation guides

## Stage 1 Status

> **Documented Placeholder**: During Stage 1, this directory is reserved as a documented placeholder. Application scaffolding will be initialized in subsequent milestones after foundational SDK engine stabilization.
