# @apps/console — Trivio Developer Console

## Overview

The authenticated developer dashboard and merchant settlement management console (`https://console.trivio.ink`).

## Planned Architecture

- **Framework:** Next.js (App Router)
- **Component Library:** Reusable settlement components from `@trivio.ink/react`
- **Deployment Destination:** `https://console.trivio.ink`
- **Responsibilities:**
  - Acquirer & payment gateway configuration
  - Custom merchant discount rate (MDR) tier definitions
  - Settlement schedule inspection & bank calendar alignment
  - Discrepancy flagging and reconciliation audit logs
  - API credential management for cloud services
